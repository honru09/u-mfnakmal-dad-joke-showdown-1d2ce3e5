## What it does

`main.py` (Python standard library only) writes one original dad joke to `/output/entry.txt`. The joke is deterministic — the same bytes on every run.

> I named my sourdough starter Kevin. He's the only one in this house who actually rises to the occasion.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
